# 🎵 Audio Folder

This folder should contain ambient background music for the birthday experience.

## How to add music

### Option 1: Recommended — "Dreamy Piano" by Clavier (Pixabay)

1. Visit: https://pixabay.com/music/ambient-dreamy-piano-197564/
2. Click "Download" (free under Pixabay Content License — no attribution required)
3. Rename the file to **`dreamy-piano.mp3`**
4. Place it in this folder (`public/audio/`)
5. Commit + push to deploy

### Option 2: Different track

If you prefer a different mood, any of these work well:

- **Cinematic Ambient Emotional**: https://pixabay.com/music/ambient-cinematic-ambient-emotional-main-7230/
- **Ethereal Ambient — Deep & Dreamy Soundscape**: https://pixabay.com/music/ambient-ethereal-ambient-deep-amp-dreamy-soundscape-313116/

Just rename the file to `dreamy-piano.mp3` (the code expects this name).

### Option 3: No music

The site works perfectly without music. The music toggle in the top-right will just stay muted — no error.
